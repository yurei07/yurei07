### ABOUT

> *Prizrak* is Russian for "ghost". *Yurei* is Japanese for the same thing.
> Quiet, always running in the background, usually somewhere in a terminal.

I'm interested in how computers work under the hood: operating systems, the terminal, and the tools that keep servers running.
My main focus is **systems programming** and **DevOps**.

I use Linux every day and run **NixOS**, because I like that a whole system can be described in code and rebuilt anywhere.
I enjoy keeping my configuration clean and documented.

**Right now**

- Learning **C++** to understand how software works close to the hardware
- Learning **Python** for scripts and automation
- Learning **DevOps**: Linux servers, Docker and automation
- Building small projects and publishing them here
